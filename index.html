Hospitality Business Finder

Finds restaurants, pubs, cafes, service stations & more from any Australian town via Google Places. Loads all Australian postcodes for suburb lookup. All processing happens in your browser.

1. API Key — your own key, pasted in-browser, never sent to any server

How to get a Google Places API key →
1. Go to Google Cloud Console → Credentials
2. Click "Create Credentials" → "API Key"
3. Click "Enable API and Services" → search for "Places API" → enable it
4. (Recommended) Restrict your key: click the key → under "Application restrictions" → choose "HTTP referrers" → add https://hospo-finder.vercel.app/*
5. Copy the key and paste it above
⚠️ Free tier: Google gives $200/mo free credit — covers thousands of searches. You won't be charged if you stay within that.
